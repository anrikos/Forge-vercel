# Forge Vercel

Проект веб-приложения со статической графической частью и серверными Edge/Serverless функциями на Node.js, разработанный специально для мгновенного развертывания в облаке Vercel.

**Живой проект доступен по адресу:** [forge-vercel-hazel.vercel.app](https://vercel.app)

---

## 🛠 Структура проекта

Проект оптимизирован под бессерверную архитектуру Vercel и не требует локальной сборки или установки сторонних пакетов:

* **Frontend:** Фронтенд-интерфейс приложения (`index.html`).
* **Backend:** Serverless-функции на Node.js в папке `api/` (каждый файл внутри этой директории автоматически становится изолированным API эндпоинтом).
* **Конфигурация:** Настройки маршрутизации, проксирования и окружения (`vercel.json`).

```text
├── api/             # API эндпоинты (Node.js функции)
├── index.html       # Главная страница (Фронтенд)
└── vercel.json      # Конфигурация развертывания Vercel
```

---

## 🚀 Развертывание (Deployment)

Проект полностью управляется и развертывается на стороне Vercel. Никаких дополнительных действий на локальной машине не требуется:

1. **Автоматический деплой (Git Integration):** 
   При каждом `git push` в ветку `main` вашего GitHub-репозитория Vercel автоматически подхватывает изменения, изолирует эндпоинты в папке `api/` и обновляет production-версию сайта.

2. **Serverless среда:** 
   Все бэкенд-запросы обрабатываются на стороне Vercel с использованием оптимального рантайма (Node.js), настроенного через `vercel.json`.
