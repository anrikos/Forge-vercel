# Prompt Market Analyzer 🛒🤖

Язык / Language: [English (Английский)](README.md) | **Русский**

---

Умное веб-приложение для автоматизации анализа цен на продукты в различных торговых сетях. Сервис формирует детализированные промпты для нейросетей, поддерживает голосовой ввод списков товаров и умеет работать напрямую с API Google Gemini через Serverless-функции на Vercel Edge.

**Живой проект доступен по адресу:** [forge-vercel-hazel.vercel.app](https://vercel.app)

## ✨ Возможности
* **Голосовой ввод (Speech Recognition):** Возможность надиктовать список магазинов и продуктовую корзину голосом на русском языке.
* **Прямая интеграция с Gemini API:** Отправка запросов к ИИ прямо из интерфейса через легкий бэкенд-прокси на Vercel.
* **Безопасность данных:** Ваш личный API-ключ сохраняется исключительно локально в браузере (`localStorage`).
* **Мультиплатформенность:** Если ключ отсутствует, приложение позволяет в один клик скопировать промпт и открыть его в ChatGPT, Microsoft Copilot или Google AI.
* **Modern UI:** Футуристичный адаптивный интерфейс с темной темой и поддержкой трендового эффекта Glassmorphism.

## 🛠 Структура проекта
Архитектура проекта спроектирована специально под облачную инфраструктуру Vercel, работает без локальной сборки и тяжелых зависимостей:
* **`index.html`** – Фронтенд-интерфейс приложения на чистом JavaScript, CSS переменных и иконках FontAwesome.
* **`api/`** – Серверные функции (Serverless Functions) на Node.js для безопасного перенаправления запросов к API.
* **`vercel.json`** – Настройки маршрутизации и правил развертывания Edge-среды.

```text
├── api/             # API эндпоинты (Serverless Node.js функции)
├── index.html       # Веб-интерфейс приложения (Фронтенд)
└── vercel.json      # Конфигурация развертывания Vercel
```

## 🚀 Развертывание (Deployment)
1. Подключите данный GitHub-репозиторий к вашему личному кабинету Vercel.
2. Любой `git push` в ветку `main` автоматически инициирует сборку и обновит рабочую production-версию сайта.
